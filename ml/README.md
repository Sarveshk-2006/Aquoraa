# Machine Learning Subsystem Boundary

> **Phase Boundary Notice**: ML pipelines, model training, feature extraction, and residual calibration are strictly scheduled for Phase 7 & Phase 8.

## Folder Organization
- `ml/features/`: Spatial-temporal feature engineering pipelines.
- `ml/training/`: Model training scripts and physics-loss implementations.
- `ml/inference/`: Real-time nowcast inference wrappers.
- `ml/models/`: Saved model weights and architecture definitions.
- `ml/calibration/`: Residual error calibration models coupling physics to ML.
