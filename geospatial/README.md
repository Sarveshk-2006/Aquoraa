# Geospatial Processing Subsystem

> **Phase Boundary Notice**: GIS downloading, raster processing, OpenStreetMap parsing, and satellite imagery processing begin in Phase 2.

## Modules Overview
- `geospatial/osm/`: OpenStreetMap network extraction & road processing.
- `geospatial/dem/`: Elevation raster tile slicing & hydro-delineation processing.
- `geospatial/landcover/`: Land cover, soil, and impervious surface processing.
- `geospatial/satellite/`: Sentinel-1/2 SAR imagery preprocessing.
