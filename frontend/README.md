# Aquora Web Application Frontend

React + TypeScript + Vite + Tailwind CSS frontend shell for **AQUORA — Urban Flood Intelligence & Response Platform**.

---

## Tech Stack
- **Core Framework**: React 18 & TypeScript (Strict Mode)
- **Build Tool**: Vite
- **Styling**: Tailwind CSS & Framer Motion
- **State Management**: Zustand & TanStack Query (v5)
- **Map Boundary**: MapLibre GL JS
- **Icons**: Lucide React

---

## Commands

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Strict TypeScript type checking
npm run lint

# Production build
npm run build
```
