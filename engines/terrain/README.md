# Terrain Engine

## Responsibilities (Phase 4+)
- Derive slope, aspect, and flow direction (D8 / D-Infinity algorithms) from digital elevation models (Copernicus DEM).
- Automatically delineate urban micro-catchments and flow paths.
- Generate topographic index maps for surface water accumulation modeling.

> **Phase 0 Status**: Interface definition only. Processing begins in Phase 4.
