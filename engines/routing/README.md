# Routing Engine

## Responsibilities (Phase 10+)
- Intersect 0–3h dynamic flood depth predictions with OpenStreetMap road segment geometries.
- Dynamically recalculate edge travel weights based on water depth thresholds (e.g., vehicle cutoff at 15cm-30cm depth).
- Generate travel window safety predictions and alternative evacuation corridors.

> **Phase 0 Status**: Interface definition only. Routing algorithms implemented in Phase 10.
